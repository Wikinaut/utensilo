Use case 1: Possible utensilo dimensions from fabric size

HeightWidthDepthCorner section
Height = Fabric height − Depth/2 − 2×Seam allowance − Top fold
Width = Fabric width/2 − Depth − Seam allowance
Corner section = Depth / √2, rounded to one decimal
